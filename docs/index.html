What is RAG?

Retrieval-Augmented Generation (RAG) gives a large language model an open book. Before the model answers, a retriever searches your own documents for the passages most relevant to the question and puts them in the prompt. The model then answers from that evidence instead of guessing — which means fresher knowledge, fewer hallucinations and answers you can trace back to a source.

  1. Ingest documents
  2. Chunk them
  3. Embed each chunk
  4. Store vectors
  5. Retrieve the best matches
  6. Generate a cited answer
